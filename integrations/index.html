FAQ

Common integration questions.

Does NovaOps AI replace my existing CRM?
No — NovaOps AI connects to your existing CRM, it doesn't replace it. We sync data in and out of GoHighLevel, HubSpot, Salesforce, and others. Your team keeps using the tools they know. We just make everything happen automatically inside them.
How long does integration take?
For supported platforms, setup typically takes 5 minutes — you share credentials, we handle the rest. Full activation of your automations is usually complete within 14 days. Custom integrations take 2–3 business days from kickoff call to live.
Is there an API cost for integrations?
For most platforms, API access is included in your existing subscription (HubSpot, Salesforce, Calendly, etc.). For communication channels like Twilio SMS or SendGrid email, you pay those providers directly for usage. We'll give you a clear cost estimate before we start so there are no surprises.
Can I integrate multiple CRMs at the same time?
Yes. Some clients run HubSpot for marketing and GoHighLevel for sales, for example. We can sync leads across multiple CRMs and route them intelligently. We'll design the data flow during your onboarding call.
What about data security during integrations?
All integrations use OAuth or encrypted API keys — we never store plaintext passwords. Data in transit is encrypted via TLS 1.3. We request only the scopes needed for each integration. Your data is never shared with third parties or used to train AI models.
