# Maintenance Reports

Auto-generated by the [Website Maintenance System](../maintenance/README.md).

| Folder | Cadence | Contents |
| --- | --- | --- |
| [`seo/`](./seo) | Daily | SEO audit reports (`YYYY-MM-DD.md`), `latest.md`, `latest.json` |
| [`design/`](./design) | Daily | Design/UI audit reports + `screenshots/<date>/` (screenshots are git-ignored and uploaded as CI artifacts) |
| [`weekly/`](./weekly) | Sundays | Growth optimization reviews (`YYYY-MM-DD-growth-review.md`) |

`latest.md` in each folder always points at the most recent run.

## Visual regression baseline

The design audit compares each run's screenshots against an approved baseline in
`design/baseline/`. To approve the current look as the baseline, copy a day's
screenshots there:

```bash
cp -r reports/design/screenshots/<date>/* reports/design/baseline/
```

Future runs flag screenshots that differ from the baseline in the Visual
Regression Report.
