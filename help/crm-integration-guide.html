Connecting your CRM to NovaOps AI

Full setup guides for GoHighLevel, HubSpot, Salesforce, and Pipedrive — including field mapping, pipeline configuration, webhook setup, and how to fix sync issues.

GoHighLevel (GHL)

GoHighLevel is our recommended CRM for most clients. NovaOps has a native integration that enables deep pipeline automation, contact tagging, conversation AI, and appointment booking all within GHL.

1

Generate your GHL API key

In GHL, go to Settings → API Keys → Create New Key. Set access to "All" for full automation capabilities. Copy the key — you'll need it in the next step.

2

Add the API key to NovaOps

In your NovaOps dashboard, go to Integrations → CRM → GoHighLevel. Paste your API key and sub-account ID. Click "Test Connection" — you should see a green checkmark within 10 seconds.

3

Map your pipeline stages

Select the GHL pipeline you want NovaOps to control. Then map each AI-driven stage to the corresponding GHL stage (e.g., "AI Contacted" → "Attempted Contact", "Appointment Booked" → "Appointment Set").

4

Configure inbound webhook

In GHL, go to Settings → Webhooks → Add Webhook. Paste the NovaOps webhook URL found in Integrations → Inbound Webhooks. Select "Contact Created" and "Opportunity Updated" as trigger events.

HubSpot

HubSpot integration uses OAuth 2.0 for a secure, no-password connection. You'll need a HubSpot account with at least Starter CRM access. Marketing Hub or Sales Hub are recommended for full automation features.

1

Authorize via OAuth

In NovaOps dashboard → Integrations → HubSpot → click "Connect HubSpot." You'll be redirected to HubSpot's authorization screen. Log in with your HubSpot admin account and approve the requested permissions.

2

Configure contact property mapping

After authorization, map HubSpot contact properties to NovaOps fields. Essential mappings: firstname → first_name, phone → phone, hs_lead_status → lead_status, lead_source_detail → lead_source.

3

Set up HubSpot workflows to trigger NovaOps

In HubSpot → Workflows → New Workflow → Contact-based. Set the trigger to "Form submitted" or "List membership." Add an action: "Send webhook" and paste your NovaOps inbound webhook URL. This fires NovaOps for every new lead matching your criteria.

Salesforce

Salesforce integration requires a Salesforce System Administrator account and the Salesforce Flow Builder or Process Builder for outbound triggers. Connected App credentials are used for secure API access.

1

Create a Connected App

In Salesforce, go to Setup → App Manager → New Connected App. Enable OAuth settings. Add the callback URL: https://app.nova-ops.space/auth/salesforce/callback. Save and copy the Consumer Key and Secret.

2

Enter credentials in NovaOps

In NovaOps → Integrations → Salesforce, paste your Consumer Key, Consumer Secret, and Salesforce instance URL (e.g., https://yourorg.my.salesforce.com). Click "Authorize" to complete OAuth flow.

3

Create outbound message or flow

In Salesforce Flow Builder, create a Record-Triggered Flow on Lead object (Created). Add an HTTP Action step calling your NovaOps webhook URL with the lead data as the JSON body. Activate the flow.

Pipedrive

1

Get your Pipedrive API token

In Pipedrive, click your profile icon → Personal preferences → API. Copy your personal API token. This token identifies your requests — keep it confidential.

2

Connect in NovaOps

Go to Integrations → Pipedrive. Enter your API token and your Pipedrive company domain (e.g., yourcompany.pipedrive.com). Select which pipeline NovaOps should interact with.

3

Add webhooks in Pipedrive

In Pipedrive → Tools → Webhooks → Add webhook. Set the event to "person.added" and "deal.added". Enter your NovaOps inbound webhook URL. Pipedrive will POST to NovaOps every time a new person or deal is created.

Webhook payload format

When NovaOps receives an inbound webhook, it expects JSON in this format. Custom CRM integrations should send data matching these fields.

{ "first_name": "Sarah", "last_name": "Johnson", "phone": "+15551234567", "email": "sarah@example.com", "lead_source": "facebook_ads", "service_type": "roof_replacement", "city": "Austin", "crm_id": "contact_abc123" }

All fields are optional except phone or email (at least one required). Additional fields are stored as custom attributes and can be used in message templates.

Troubleshooting sync issues

Lead created in CRM but NovaOps isn't responding

Check your webhook delivery logs in your CRM. Verify the webhook URL is correct and active. In NovaOps → Integrations → Webhook Logs, confirm whether the payload was received. A common cause is a missing required field (phone or email) in the webhook payload.

CRM stages not updating when AI takes action

Confirm your pipeline stage mapping is saved. Go to Integrations → CRM → Stage Mapping and verify each action maps to a valid stage in your CRM. If stages were renamed in your CRM recently, re-map them here.

Duplicate contacts being created

Enable deduplication in Integrations → Settings → Deduplication. Set the match key to "email" or "phone." NovaOps will check for an existing contact before creating a new one. For GHL, enable "Contact Dedup" in GHL settings as well.
